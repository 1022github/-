# 🏠 成都二手房预测分析系统

基于 Python 的成都二手房数据可视化与价格预测工具，可对二手房市场数据进行多维度分析与价格建模。

---

## 📌 项目简介
本项目以成都二手房公开数据为基础，实现了：
- 二手房市场数据清洗与结构化处理
- 房价分布、区域均价、户型占比等多维度可视化分析
- 基于机器学习模型的二手房价格预测
- 提供简易图形界面，支持用户交互查询与分析

---

## 🛠️ 技术栈
- **语言**：Python 3.x
- **数据处理**：Pandas
- **可视化**：Matplotlib
- **图形界面**：PyQt
- **数据文件**：`data.csv`（二手房源数据）
